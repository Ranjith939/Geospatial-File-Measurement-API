# Sample data

Generated by `generate_samples.py` (`.venv/Scripts/python sample-data/generate_samples.py`). Every
shape is authored in UTM zone 43N (EPSG:32643, near Bengaluru) where its true size is known exactly,
then written in that CRS or converted to WGS84. The test suites assert these values.

| File | Contents | Expected |
|---|---|---|
| `survey.zip` | one irregular 7-vertex parcel, WGS84 with `.prj` (used by the landing story) | 145,337.50 m² (14.53 ha); `survey_m2` holds the same value |
| `polygon.kml` | 1 km square; 400×250 m parcel with a 100×100 m hole | 1,000,000 m² (100 ha); 90,000 m² |
| `line.kml` | L-shaped road, 600 m + 800 m | 1,400 m |
| `point.kml` | one survey marker | `measurement_status: not_required` |
| `mixed_geometry.kml` | 2 polygons, 1 line, 1 point, a bow-tie, broken coordinates, a Point+Line collection, in two folders | 7 features: 4 success, 2 failed, 1 unsupported |
| `valid_shapefile.zip` | 3 parcels in EPSG:32643 (projected, measured as-is) | 200,000 / 100,000 / 90,000 m² |
| `roads_wgs84.zip` | 2 lines in EPSG:4326 | 2,000 m; 1,000 m |
| `land_parcels.zip` | 198 parcels in EPSG:4326; #83 and #141 are self-intersecting | 196 success, 2 failed; each good parcel's `survey_m2` equals its measured area |
| `invalid_shapefile.zip` | parcels without `.shx` | 422 `INVALID_SHAPEFILE` |
| `missing_crs.zip` | parcels without `.prj` | features returned, measurements fail with `MISSING_CRS` |
| `corrupt.zip` | ZIP header followed by junk | 422 `CORRUPT_ARCHIVE` |

The tests also build edge cases in memory: an empty ZIP, path traversal, symlinks, an unreadable
`.prj` (`INVALID_CRS`) and a local site-grid `.prj` (`UNSUPPORTED_CRS`).
