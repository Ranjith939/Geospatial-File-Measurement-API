POST/api/files/

Upload a geospatial file

Accepts .kml or a .zip containing a Shapefile (.shp, .shx, .dbf, optional .prj). Validation, extraction, CRS detection, reprojection and measurement run synchronously; the response carries the final status.

Headers

Content-Type: multipart/form-data

Parameters

fileform field · requiredKML or ZIP, max 50 MB (configurable)

Error responses

400NO_FILE, EMPTY_FILE
413FILE_TOO_LARGE
415UNSUPPORTED_FILE_TYPE
422INVALID_KML, CORRUPT_ARCHIVE, EMPTY_ARCHIVE, UNSAFE_ARCHIVE, INVALID_SHAPEFILE

Request

curl -F "file=@sample-data/survey.zip" {{ request.scheme }}://{{ request.get_host }}/api/files/

Example response · 201

{
  "id": 42,
  "filename": "survey.zip",
  "file_type": "SHAPEFILE",
  "format": "ESRI Shapefile",
  "status": "completed",
  "crs": "EPSG:4326",
  "measurement_crs": ["EPSG:32643"],
  "feature_count": 1, "successful_count": 1, "failed_count": 0,
  "components": [{"name": "survey.shp", "size": 284}, "…"],
  "stages": [{"stage": "validating", "status": "done", "duration_ms": 2.1}, "…"]
}

Example error · 422

{"error": {"code": "INVALID_SHAPEFILE",
  "message": "The uploaded ZIP does not contain a valid Shapefile structure.",
  "details": {"expected": [".shp", ".shx", ".dbf"],
              "missing": {"parcels/parcels": [".shx"]}}}}

      GET/api/files/{id}/measurements/
      
Retrieve measurements

      
One entry per feature. Polygons carry area, lines carry length, points report measurement_status: "not_required". Failed and unsupported features keep their geometry and properties and carry an error code.

      

        

          
Parameters

          

            
idpath · requiredFile id

            
statusquery · optionalsuccess · failed · unsupported

            
include_geometryquery · optionaltrue (default) · false

          

          
Error responses

          
404FILE_NOT_FOUND
422INVALID_REQUEST

          
Request

          
curl "{{ request.scheme }}://{{ request.get_host }}/api/files/42/measurements/?status=failed"
