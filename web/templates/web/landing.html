{# 09 — Failure isolation #}

09 / ISOLATION

One bad feature
should not break
the file.

Each feature's steps run in their own error boundary. A self-intersecting parcel fails with an explanation; its neighbours are measured as usual and the file completes with errors, not as a failure.

API

Three endpoints.

  • POST/api/files/

    Upload a KML or zipped Shapefile; processed synchronously.

  • GET/api/files/{id}/

    File information: format, CRS, counts, stages.

  • GET/api/files/{id}/measurements/

    Per-feature area, length, CRS, properties and errors.
